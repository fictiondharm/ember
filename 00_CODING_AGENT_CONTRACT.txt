NON-NEGOTIABLE:
1. Backend is authoritative.
2. Do not invent new entities/states/endpoints if the PRD already defines them.
3. Agent mutations happen only through validated backend tools.
4. Recovery/payment/cargo reassignment requires approval in MVP.
5. Every important state change creates an event.
6. External dependencies require a fallback.
7. Never fake blockchain confirmation.
8. Never put provider secrets in source code.
9. Keep the golden demo working after every change.
10. If a requirement is ambiguous, choose the smallest implementation consistent with the Master PRD and document the assumption.

Business creates 1T Bengaluru→Chennai shipment
